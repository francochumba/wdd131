Classes

A class is a blueprint used to create objects. It defines properties (data) and methods (actions) that the object can perform. Classes help organize code, improve structure, and make programs reusable. 

public class Person
{
    public string Name;
}

This example creates a Person class with a Name property.

Methods

A method is a function inside a class that defines an action an object can perform. Methods contain instructions that execute when the method is called. 

public class Person
{
    public void Speak()
    {
        Console.WriteLine("Hello");
    }
}

This method displays the message "Hello" when it is executed.

Abstraction

Abstraction is the concept of hiding complex implementation details and showing only the essential features. It allows programmers to focus on what an object does rather than how it works internally. 

public abstract class Animal
{
    public abstract void MakeSound();
}

This example defines an abstract class that requires subclasses to implement the MakeSound method.

Encapsulation

Encapsulation is the practice of protecting data by restricting direct access to it. Instead, access is controlled through methods. This improves security, control, and program stability. 

public class Person
{
    private int age;

    public void SetAge(int value)
    {
        age = value;
    }
}

In this example, the age variable is private and can only be changed using the SetAge method.
